# Machine-Readable Results

- `correction_core_results.json`: central exact values, frozen Monte Carlo results, IBM reconstruction, and witness checks.
- `figure5_corrected.csv`: corrected Figure 5 table and simulation metadata.
- `ibm_aggregate_reanalysis.json`: archived count table, corrected point estimate, and finite-count bootstrap.
- `heralded_witness_results.json`: dense-state checks, tight product-effect values, finite-sample examples, and circuit resources.

All files are generated by `scripts/generate_results.py`. Exact quantities originate from integer or rational arithmetic. Monte Carlo records include fixed seeds, trial counts, and Wilson intervals.
